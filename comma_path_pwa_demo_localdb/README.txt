쉼표길 PWA 데모

핵심
- QR로 공개 URL에 접속하면 모바일 앱처럼 보이는 화면이 바로 열립니다.
- Android Chrome 등에서는 '설치' 안내가 나타나면 홈 화면 앱처럼 설치할 수 있습니다.
- iPhone은 Safari 공유 메뉴 > 홈 화면에 추가로 설치할 수 있습니다.
- 설치 후에는 standalone 모드로 실행되어 주소창 없이 앱처럼 보입니다.

배포
- Netlify / Vercel / GitHub Pages 같은 HTTPS 정적 호스팅에 이 폴더 전체를 올리세요.
- 공개 URL에서 우측 상단 QR 버튼을 누르면 현재 주소로 QR이 생성됩니다.
- manifest.webmanifest, sw.js, icon 파일이 반드시 함께 올라가야 합니다.

로컬 시연
- start_demo.bat 실행
- PC: localhost:8000
- 같은 Wi-Fi 휴대폰: 터미널에 표시된 IP 주소 접속
- PWA 설치는 HTTPS 또는 localhost 환경에서만 정상 동작합니다.

주의
- 지도/장소 검색은 OpenStreetMap 계열 공개 서비스를 사용하므로 인터넷 연결이 필요합니다.
- 쉼표 지점은 현재 프로토타입용 데이터입니다.


[Local DB 버전 변경사항]
- 순천대학교 주요 장소를 앱 자체 검색 DB에 넣었습니다.
- 검색 우선순위: 쉼표길 자체 DB → OpenStreetMap/Nominatim 보조 검색.
- 지원 예시: 정문, 공대1호관/2호관/3호관, 도서관, 학생회관, 대학본부, 웅지관, 체육관, 진리관, 청운관, 박물관.
- '공대', 'D2', '정문', '도서관' 같은 짧은 별칭으로도 검색됩니다.
- 검색 결과에서 '쉼표길 DB'와 '지도 검색' 출처를 구분해 표시합니다.
- 순천대학교 정문은 공개 데이터에 독립 POI 좌표가 명확하지 않아 공식 캠퍼스맵 배치를 바탕으로 한 시연용 대표 위치입니다.
- 나머지 포함된 캠퍼스 건물 좌표는 공개 OSM 기반 위치를 사용했습니다.
